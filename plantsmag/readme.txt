== Description ==

PlantsMag is a beautiful, modern WordPress theme designed specifically for plant enthusiasts, gardening blogs, and nature-related websites. It features:

* **Custom Post Types**: Plant Guides and Product Reviews with custom meta fields
* **Beautiful Homepage**: Hero, About, Services, Portfolio, Testimonials, Blog, Newsletter, and CTA sections
* **SEO Optimized**: Schema.org markup, Open Graph, Twitter Cards
* **Fast & Lightweight**: Optimized for performance with lazy loading and deferred scripts
* **Fully Responsive**: Mobile-first design that looks great on all devices
* **RTL Support**: Full right-to-left language support with Persian font
* **Customizer Options**: Colors, typography, header/footer settings, social media links
* **WooCommerce Ready**: Sell your products with full WooCommerce support

== Installation ==

1. Upload the theme to the `/wp-content/themes/` directory
2. Activate the theme through the 'Themes' menu in WordPress
3. Navigate to Appearance > Customize to set up your theme

== Frequently Asked Questions ==

= How do I set up the homepage? =

1. Create a new page and set it as your Static Front Page in Settings > Reading
2. The theme will automatically display the homepage sections
3. Configure sections in Appearance > Customize > Theme Options

= How do I add Plant Guides? =

Go to Plant Guides > Add New in your WordPress admin. Fill in the plant information, add care details in the sidebar meta box, and publish.

= How do I add Product Reviews? =

Go to Product Reviews > Add New. Add the review content, set the rating and pros/cons in the sidebar, and include an affiliate link if applicable.
