# PlantsMag - راهنمای کاربری

## 🌿 معرفی

PlantsMag یک قالب وردپرس حرفه‌ای برای سایت‌های گیاهان آپارتمانی، باغبانی شهری، و نقد و بررسی محصولات باغبانی است.

## 📦 نصب

1. فایل ZIP قالب را آپلود کنید: `نمایش > پوسته‌ها > افزودن`
2. قالب را فعال کنید
3. به `نمایش > سفارشی‌سازی` بروید

## ⚙️ تنظیمات

### تنظیم صفحه اصلی
1. یک صفحه جدید بسازید
2. در `تنظیمات > خواندن` آن را به عنوان صفحه اصلی انتخاب کنید

### رنگ‌ها
- `نمایش > سفارشی‌سازی > Theme Options > Theme Colors`

### هدر
- لوگو: `نمایش > سفارشی‌سازی > هویت سایت`
- دکمه CTA: `Theme Options > Header Settings`

### شبکه‌های اجتماعی
- `Theme Options > Social Media`

## 📝 انواع محتوا

### راهنمای گیاهان
- `راهنمای گیاهان > افزودن`
- فیلدهای نور، آب، رطوبت، دما

### نقد و بررسی محصول
- `نقد و بررسی > افزودن`
- امتیازدهی، مزایا/معایب، لینک خرید

## 🔧 ویجت‌ها

- **گیاهان اخیر**: نمایش آخرین راهنماها
- **خبرنامه**: فرم عضویت
- **شبکه‌های اجتماعی**: لینک‌های سوشال
